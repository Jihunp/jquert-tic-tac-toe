# jQuery Tic-Tac-Toe

This project is a simple implementation of the classic Tic-Tac-Toe game using jQuery, HTML, and CSS.
The game allows two players to take turns marking spaces in a 3x3 grid, with the objective of getting three marks in a row (horizontally, vertically, or diagonally).

### Prerequisites
- Any modern web browser (Chrome, Firefox, etc.)
- A local web server or an IDE like [VSCode](https://code.visualstudio.com/) or [Sublime Text](https://www.sublimetext.com/) with live server extensions (optional for ease of use).
